3. MCTS (Monte Carlo Tree Search)
What is it? Instead of searching all moves (minimax), it simulates thousands of random games to the end to see which moves lead to wins statistically.
Why? It's more robust and doesn't rely as heavily on a hand-crafted evaluation function.
Reversi Context: Pure MCTS is often weaker than Alpha-Beta in Reversi because Reversi is very tactical (one bad move ruins the game). However, MCTS combined with a Neural Network (like AlphaZero) is the state-of-the-art.
Feasibility: Medium. Easy to implement a basic version, but hard to make it beat ab2.

4. Reinforcement Learning (Weight Tuning)
What is it? Currently, your weights (1000 for corners, 50 for edges) are "magic numbers" we guessed. RL can learn the exact optimal values by playing millions of games against itself.
Why? A perfectly tuned evaluation function is much stronger than a deeper search with bad evaluation.
Feasibility: Medium. We can write a script to have the bot play itself and adjust weights using a simple algorithm (like Hill Climbing or SPSA).
